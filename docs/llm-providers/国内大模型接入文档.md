### 5.2 统一调用代码

```python
import os
from typing import Dict, List, Optional, Any
from openai import OpenAI
import yaml

class UnifiedLLMGateway:
    """统一LLM网关"""
    
    def __init__(self, config_path: str = "config/llm_config.yaml"):
        with open(config_path, 'r', encoding='utf-8') as f:
            self.config = yaml.safe_load(f)
        
        self.clients: Dict[str, OpenAI] = {}
        self._init_clients()
    
    def _init_clients(self):
        """初始化所有提供商的客户端"""
        for provider_id, provider_config in self.config['providers'].items():
            api_key = os.getenv(provider_config['api_key'].strip('${}'))
            if not api_key:
                print(f"Warning: API key not found for {provider_id}")
                continue
            
            self.clients[provider_id] = OpenAI(
                api_key=api_key,
                base_url=provider_config['base_url']
            )
    
    def generate(
        self,
        prompt: str,
        task_type: str,
        system_prompt: Optional[str] = None,
        **kwargs
    ) -> str:
        """生成文本"""
        # 获取该任务类型对应的模型
        model_config = self._get_model_for_task(task_type)
        provider_id = model_config['provider']
        model_name = model_config['model']
        
        # 获取客户端
        client = self.clients.get(provider_id)
        if not client:
            raise ValueError(f"Client not found for provider: {provider_id}")
        
        # 构建消息
        messages = []
        if system_prompt:
            messages.append({"role": "system", "content": system_prompt})
        messages.append({"role": "user", "content": prompt})
        
        # 调用API
        completion = client.chat.completions.create(
            model=model_name,
            messages=messages,
            **kwargs
        )
        
        return completion.choices[0].message.content
    
    def _get_model_for_task(self, task_type: str) -> Dict[str, str]:
        """根据任务类型获取模型配置"""
        model_name = self.config['default_models'].get(task_type)
        if not model_name:
            raise ValueError(f"No model configured for task: {task_type}")
        
        # 查找模型所属的提供商
        for provider_id, provider_config in self.config['providers'].items():
            for model in provider_config['models']:
                if model['name'] == model_name:
                    return {
                        'provider': provider_id,
                        'model': model_name
                    }
        
        raise ValueError(f"Model not found: {model_name}")

# 使用示例
if __name__ == "__main__":
    gateway = UnifiedLLMGateway()
    
    # 世界构建
    world_description = gateway.generate(
        prompt="请创建一个设定在1990-2025年中国杭州的故事世界",
        task_type="world_building",
        system_prompt="你是一位专业的世界构建师。"
    )

        task_type="character_creation",
        system_prompt="你是一位专业的心理学家和人物塑造专家。"
    )
```

## 六、最佳实践

### 6.1 模型选择建议

| 任务类型 | 推荐模型 | 理由 |
|---------|---------|------|
| **世界构建** | Qwen-Max | 创意能力强，结构化思考 |
| **人物塑造** | GLM-5 | 逻辑推理强，人格分析准确 |
| **事件生成** | GLM-4.7 | 因果推理能力强 |
| **叙事生成** | Kimi-K2.5 | 文学创作能力强，支持长文本 |
| **情感分析** | Qwen-Plus | 性价比高，速度快 |
| **闪光捕捉** | GLM-5 | 深度理解能力强 |

### 6.2 成本优化策略

1. **简单任务使用轻量模型**: 如情感分析、简单对话使用Qwen-Plus或GLM-4.6
2. **复杂任务使用旗舰模型**: 如世界构建、人物塑造使用Qwen-Max或GLM-5
3. **长文本使用长上下文模型**: 如叙事生成使用Kimi-K2.5（256K上下文）
4. **批量处理使用异步调用**: 减少等待时间，提高效率

### 6.3 错误处理

```python
import time
from typing import Optional

def call_llm_with_retry(
    gateway: UnifiedLLMGateway,
    prompt: str,
    task_type: str,
    max_retries: int = 3,
    **kwargs
) -> Optional[str]:
    """带重试的LLM调用"""
    
    for attempt in range(max_retries):
        try:
            return gateway.generate(prompt, task_type, **kwargs)
        except Exception as e:
            print(f"Attempt {attempt + 1} failed: {e}")
            if attempt < max_retries - 1:
                time.sleep(2 ** attempt)  # 指数退避
            else:
                raise
    
    return None
```
